# Linux VPS Learning Lab

## Overview

This repository is an educational laboratory for learning Linux server administration, networking, cybersecurity, and infrastructure management on a VPS.

The project is designed as a hands-on learning environment covering:

* Linux server administration
* SSH configuration and hardening
* Linux networking
* Firewall configuration
* Service management with systemd
* Monitoring and logging
* Backup and disaster recovery
* Secure deployment of network services
* Infrastructure migration between VPS providers

## Learning Objectives

The main objectives of this project are:

1. Learn practical Linux server administration.
2. Understand VPS networking and security.
3. Configure and harden a Linux server.
4. Deploy and manage network services in a controlled laboratory environment.
5. Learn backup, restoration, and migration procedures.
6. Document the configuration and troubleshooting process.

## Laboratory Environment

The planned laboratory environment will use:

* Linux VPS
* Ubuntu Server
* SSH
* systemd
* UFW / firewall
* Xray-based networking components
* Sanaei management panel
* Monitoring and logging tools

All configurations will be documented for educational and infrastructure-management purposes.
